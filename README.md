# She Can Foundation 🌟

A beautifully designed, fully responsive single-page landing website for the **She Can Foundation** - an NGO dedicated to empowering girls and changing the world through education, mentorship, and support.

## ✨ Features

- **Modern & Responsive UI**: Looks stunning on desktops, tablets, and mobile devices.
- **Dark/Light Mode Toggle**: Integrated theme switcher that remembers user preferences.
- **Interactive Animations**: Scroll-reveal animations, custom glowing cursor effect, and dynamic floating elements.
- **Impact Stats Counter**: Animated numbers that count up as you scroll to showcase the NGO's real-world impact.
- **Donation Modal**: A sleek popup for quick and easy contribution selection.
- **Interactive FAQ Accordion**: Expandable questions and answers.
- **Functional Forms**: Client-side validation and success states for Contact and Newsletter forms.
- **Scroll Progress Bar & Back-to-Top**: Enhances user navigation for longer content.

## 🛠️ Technology Stack

- **HTML5**: Semantic and accessible structure.
- **Vanilla CSS3**: Custom CSS variables, flexbox, grid layouts, and keyframe animations.
- **Vanilla JavaScript**: Lightweight DOM manipulation, intersection observers, and local storage usage (No heavy frameworks used).

## 🚀 Getting Started

To view this project locally, simply download or clone the repository and open the `index.html` file in your favorite web browser.

```bash
# Clone the repository
git clone https://github.com/indramohankumar/she-can-foundation.git

# Navigate into the directory
cd she-can-foundation
```

Alternatively, you can host this project for free using **GitHub Pages**.
